# Analytics & Evaluation Metrics

This module computes performance, security, and financial metrics across simulation runs.

## Planned Capabilities
- **Grid Stability Metrics**: Loss of load probability, peak-to-average ratio (PAR), grid import/export balance.
- **Economic Metrics**: Cost savings for prosumers/consumers, market clearing prices, trading volume.
- **Security & Privacy Metrics**: Detection rate of FDI attacks, privacy loss parameter (epsilon), latency of consensus.
