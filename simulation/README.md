# Simulation Engine

This module is dedicated to the digital twin simulation of the microgrid environment.

## Planned Capabilities
- **Prosumer & Consumer Simulation**: Generation (Solar PV), Consumption loads, Battery Energy Storage Systems (BESS), Electric Vehicles (EV).
- **Time-step Simulation**: Discrete time resolution (e.g. 15-minute / hourly intervals) synthetic load and weather curves.
- **Smart Meter Emulation**: In-memory Python meter telemetry generation (no physical hardware required).
